## 💡 О проекте

**ForgePack** — это высокопроизводительный self-hosted Telegram-бот, написанный на **Go** с использованием интеграции легковесных **Python**-нейросетей. 
Бот создан специально для слабых VDS-серверов. Он защищен встроенной системой очередей, чтобы тяжелые задачи (например, вырезание фона из видеокадров) не вызывали отказ сервера (OOM или 100% CPU usage).

## ✨ Возможности

- 🚀 **Производительность:** Ядро на Golang обеспечивает сверхбыструю обработку сообщений и конкурентность.
- 🎨 **Удаление фона:** Интегрированная нейросеть `U-2-Net` (через `rembg`) позволяет стирать фон как на фото, так и на видео (покадрово). Просто добавьте флаг `-B` к вашему медиа!
- 🔄 **Автоконвертация:** 
  - Загрузили видео в статический пак? Бот аккуратно извлечет первый кадр.
  - Загрузили фото в видеопак? Бот превратит его в 3-секундное видео.
  - Любые фото и видео автоматически приводятся к жестким стандартам Telegram (max 512px по одной стороне, VP9 codec для webm, <3 сек длительности).
- 🔀 **Форк Стикерпаков:** Увидели крутой пак у друга? Команда `/fork` полностью скопирует его стикеры в ваш личный пак для дальнейшего редактирования.
- 🛡 **Защита сервера (Queue Limits):** Встроенная очередь настраивается через `.env` (например, не более 3 одновременных задач). Все лишние запросы вежливо отклоняются, пока сервер не освободится. Владелец бота (`OWNER_ID`) имеет иммунитет к очереди.
- ⚡ **RAM Boost (tmpfs):** Поддержка монтирования временной папки в ОЗУ для обработки кадров видео, что сильно экономит ресурс SSD/HDD на слабых VDS.

## 🛠 Настройка и Запуск

Проект полностью упакован в `Docker`, что делает его развертывание делом двух минут.

### Требования
- Любой Linux-сервер (подойдет даже слабая VDS с 1GB RAM)
- Установленный `Docker` и `Docker Compose`

### Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_АККАУНТ/forgepack.git
   cd forgepack
   ```

2. Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```

3. Отредактируйте `.env`, вставив ваши данные:
   ```ini
   BOT_TOKEN=123456789:ABCDefghIJKlmnOPQRSTuvwxyz # Токен от @BotFather
   OWNER_ID=123456789 # Ваш Telegram ID (получить через @ShowJsonBot или аналогичный)
   MAX_QUEUE_SIZE=3 # Максимум тяжелых задач одновременно
   BOOST_BY_RAM=true # Использовать ОЗУ для кэширования
   RAM_DISK_PATH=/tmp/ramdisk # Путь монтирования tmpfs внутри контейнера
   ```

4. *(Опционально)* Если вы включили `BOOST_BY_RAM=true`, раскомментируйте блок `tmpfs` в файле `docker-compose.yml`, чтобы бот не «насиловал» диск.

5. Запустите бота:
   ```bash
   docker-compose up -d --build
   ```

## 🎮 Использование

Бот работает в приватном (Self-Hosted) режиме. Это значит, что доступ к нему есть только у вас (`OWNER_ID`). Вы можете выдавать доступ своим друзьям командой:
`/add_user <Telegram ID>`

### Основные команды бота:
* `/newpack` — Создать новый пустой стикерпак.
* `/fork` — Скопировать любой существующий чужой пак к себе.
* `/start` — Помощь и информация.

### Модификаторы сообщений (Подписи)
Когда бот находится в режиме ожидания нового стикера, отправьте ему фото или видео.
* Прикрепите подпись **`-B`** или **`--Background`** к медиафайлу, чтобы бот автоматически удалил с него задний фон! 🧠
